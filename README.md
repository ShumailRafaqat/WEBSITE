# Careflare Visibility

Premium interactive React + TypeScript site for SEO, Google Ranking, Google Visibility, and Marketing.

## Run

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

Theme: warm paper (`mist`/`sand`) + ink + pine + gold. Not a generic agency card layout.

All metrics and ranking positions are labeled demo / illustrative. No performance guarantees.
